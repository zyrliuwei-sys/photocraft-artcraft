## What this site does

PhotoCraft ArtCraft is an English-language guide to PhotoCraft, the open-source image editor in the ArtCraft suite. This site helps readers understand the editor, find official downloads, install an appropriate build, and plan everyday editing tasks. We also explain how PhotoCraft relates to other ArtCraft applications, including VectorCraft, so readers can choose a tool for their work.

Our audience includes people trying an open-source editor for the first time and people checking whether an existing workflow can move between applications. The guides focus on practical questions: choosing a platform package, keeping original documents safe, checking PSD compatibility, and identifying useful information when something goes wrong. Desktop download links lead directly to the project's official GitHub releases. We do not host installers or distribute modified desktop packages.

## Who maintains it

This website is maintained by an independent developer. The maintainer is responsible for selecting topics, preparing the site's explanations, reviewing links, and handling messages about the website. No additional team members, professional credentials, or employment history are claimed here. You can reach the maintainer through the email address on our [Contact page](/contact).

## How the content is prepared

Content is manually curated from official documentation, GitHub release notes, and practical usage checks; it is not an automatically scraped feed. Articles link to primary sources so readers can distinguish a project's documented behavior from this site's guidance. When a procedure is offered for readers to reproduce, it is described as a procedure, rather than presented as a completed test.

Measured claims require an actual recorded test and enough context to interpret it. We do not invent benchmark results, compatibility percentages, or device-specific timings. Where no measurements are available, an article explains what to inspect and record instead. Software changes quickly, so check the release referenced by an article and the current official notes before relying on a feature for important work. Please report a broken link, unclear instruction, or outdated claim so it can be reviewed.
